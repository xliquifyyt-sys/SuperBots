Super Bots Map Art Brief

Every map's current layout with a background prompt written for that map specifically, plus the five shared terrain kits. Copy a prompt, paste it into Scenario, and the house style is already appended.

How this splits

Backgrounds per map, terrain per theme

Backgrounds are one painted image each, so every map gets its own. That is what makes Ember Pit read as a volcano interior and Magma Works as a foundry, even though both are lava.

Terrain is different. Tiles repeat across a map and have to butt against each other seamlessly, so the two maps sharing a theme share one tile kit. Five kits cover all ten maps. Each map below names the kit it uses.

Background style suffix — already included in every Copy button

game background art for a 2D side-scrolling platformer, painted cartoon style, soft atmospheric depth with distance desaturating toward the sky colour, clean readable shapes, no characters, no platforms, no foreground ground line, no text, seamless horizontal tiling, wide 16:9 composition

Terrain style suffix — already included in the kit Copy buttons

2D game terrain tile, painted cartoon style, thick dark outline on the outer silhouette, cel shaded with two tones, brightly lit top surface and a darker front face with a hard edge between them, orthographic side view, seamless horizontal tiling on the left and right edges, transparent background, no characters, no text

Negative prompt — paste once, leave unchanged for every run

photorealistic, 3D render, blurry, soft focus, painterly noise, drop shadow, characters, robots, vehicles, text, watermark, logo, perspective distortion, vanishing point, tilted horizon, cropped

Generate one background you are happy with first, then train a Scenario model on it and run the other nine through that model. Ten backgrounds prompted independently will drift apart, and drift only shows once you see them side by side.

The five terrain kits

Generate each kit as one wide strip, then cut it into six pieces. Generating the pieces separately gives edges that do not match, and mismatched edges show on every platform in the game rather than in one place.
