# M0-10: AI predicts Chain Arc with the same outline test as the sim

Found in M0-03 review: `src/ai/planner.js` (~line 193) still scores Chain Arc hits with a 0.7 circle around each
bot's centre; the sim now uses `distSegPoly` against the hull with `BOTS.volt.s1.beamHalfWidth`.

## Acceptance
- [x] Planner reuses the sim's outline test and `beamHalfWidth` (no literal radius in planner.js).
- [x] determinism 6, features, bughunt 2 green; `node test/balance.mjs 3` before/after in the PR.

## Log

- 2026-10-16 (gameplay, branch agent/M0-10-ai-chainarc-outline):
  - `src/ai/planner.js` chainArc case now counts hits with the sim's own test: it imports `distSegPoly` (already
    exported from `src/core/sim.js`, no sim edit) and checks the beam segment (caster to caster + map diagonal,
    as in `World.chainArc`) against `w.botPoly(o)` within `sp.beamHalfWidth` (`BOTS.volt.s1.beamHalfWidth`).
    The arc-bonus radius uses `sp.arcRange` instead of a literal 6. No literal radius is left in the case.
  - Also fixed a bug in the same case: `score > best.score` compared a raw score against one already scaled by
    `0.7 + iq*0.5` (1.175 on hard). That meant a later aim with more hits could lose to an earlier one
    (e.g. 7 hits = 225 raw lost to 6 hits + bonus = 229.1 scaled). The two scores are now compared on the same scale.
  - `docs/spec/07-ai.md` Chain Arc line updated.
  - Verified with a scratch harness: 300 random 8-bot line-ups with Volt aiming at each enemy, compared against
    real `World.chainArc` damage events. The old 0.7 circle mispredicted 1452/2100 aims. The planner's best-hit count
    now matches the sim's best in 300/300 positions (before the comparison fix: 77 mismatches).
  - Gates: determinism 6, rules, spawns, headless 20, features, bughunt 2, bughunt 3, balance-gate 2, online,
    online-browser, online-maps, online-settings-layout and browser all pass.
  - `node test/balance.mjs 3` before (origin/main) and after are identical, as expected. In a 1v1 duel there is only
    one enemy and the AI aims at its centre, so both tests count 1 hit and the arc bonus needs a second enemy.
    The change only affects games with 3 or more bots (headless 20 8-bot stats moved, e.g. gravitas avg dmg 103 -> 101):
    ```
    168 duels, avg turns 7.7
    bulwark 67% 102 | magmaw 40% 64 | volt 52% 112 | warden 60% 97
    skyla 14% 49 | phantom 17% 42 | ricochet 55% 93 | gravitas 43% 74
    ```
