## Log

- 2026-10-14 (gameplay, branch `agent/M0-04-design-defaults`):
  - D-2 built. Power-ups carry `turnsLeft`, set from `TURN.powerupExpire` (6) at spawn. At each `startTurn`, before the spawn roll, every power-up loses 1. At 0 it is removed with a `powerupExpire {x,y,id}` event; otherwise the sim emits `powerupCountdown {x,y,id,turnsLeft}`. This step draws no RNG, so the draw order is unchanged. A power-up can be picked up on 6 turns counting its spawn turn, and its slot can refill on the turn it expires. `powerupSpawn` now also carries `turnsLeft`.
