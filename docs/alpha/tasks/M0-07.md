# M0-07: Online lobby map labels are hardcoded and wrong

`src/ui/online.js:18` hardcodes the map labels for the online lobby settings instead of reading
them from `src/core/maps.js`. Two labels already differ from the real map names:

| id | online.js label | `MAPS[id].name` |
|---|---|---|
| `frozenkeel` | Frost Hollow | Frozen Keel |
| `glacierfort` | Glacier Fort | Glacier Fortress |

Found during M0-02. The same stale "Frost Hollow" name was in the README and docs/spec/06.

## Fix

Build the `map` option list from `MAP_IDS` / `MAPS[id].name`, keeping `random: 'Random'` first.
Then a renamed or added map cannot drift again.

- [x] The online lobby map names equal the `maps.js` names for every id. Add an assertion that
