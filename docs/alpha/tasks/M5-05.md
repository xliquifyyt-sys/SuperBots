# M5-05: Configurable game-server base URL for native builds

Found in M0-01 review: `src/ui/online.js` decides whether a server exists from a
`<meta name="superbots-host">` flag that `server/index.js` rewrites, and all fetch/WebSocket calls are same-origin.
A Capacitor build loads a local index.html still marked `static`, so it would never reach the server.
The server also rewrites index.html by string replace on every request with no check that it matched.

## Acceptance
- [ ] One config point (meta or build constant) sets the server base URL; both `fetch` and `new WebSocket` use it.
- [ ] Static web build stays 404-free (browser gate); served build and a cross-origin base URL both reach `/api/config` (new test).
- [ ] Server caches the rewritten index.html at startup and fails loudly if the marker is missing (test asserts `GET /` contains `content="server"`).
