# M0-16: AI Chain Arc scoring counts teammates on the beam when friendly fire is on

Found in the M0-10 review (PR #27). `World.chainArc` (src/core/sim.js ~589) hits every alive bot on the
beam except the caster, teammates included; damage to a teammate is zeroed only when
`settings.friendlyFire` is off (sim.js ~783). The planner's chainArc case counts hits among `enemies` only,
so in team modes with friendly fire on it cannot see the cost of arcing through an ally.

Optional in the same task: the beam segment (caster → caster + aim × map diagonal) is computed in both
sim.js and planner.js; a shared exported helper would stop the two copies drifting.

## Acceptance
- [x] With `friendlyFire` on, the planner's chainArc score subtracts a penalty per teammate the beam hits
      (weight in `src/core/defs.js`, no literals in planner.js); with it off, scoring is unchanged.
- [x] A test (new file or added assertions) sets up a teammate in the beam line and shows the AI picks a

- [x] determinism 6, features, bughunt 2, balance-gate 2 green; `node test/balance.mjs 3` before/after in the PR.
