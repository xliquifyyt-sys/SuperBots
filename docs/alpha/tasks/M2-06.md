# M2-06: AI Chain Arc arc-jump bonus ignores teammates the arc can jump to

Found in M0-16 (worker and reviewer notes). In `World.chainArc` the arc jumps from the beam's
first hit to the nearest bot not already hit, which can be a teammate. The planner's `case 'chainArc'`
arc bonus only looks for enemies near the aimed target, so with `friendlyFire` on it can over-value an
arc that will chain into an ally. Also noted: with friendly fire on the chainArc score can now be
negative; it is simply outscored today, but any future minimum-score threshold for instant specials
must account for it.

## Acceptance
- [ ] With `friendlyFire` on, the planner predicts the arc jump target the same way `World.chainArc`
      does (nearest un-hit alive bot within `sp.arcRange`) and applies `sp.aiTeammatePenalty` when it is
      a teammate; with friendly fire off, scoring is unchanged (no literals in planner.js).
- [ ] Added assertions in `test/features.mjs` (lines added only) with an ally closest to the beam's first
      hit show the AI choosing a different aim with friendly fire on.
